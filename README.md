## Что было сделано

Разработано клиент-серверное веб-приложение для проверки прогноза погоды по заданному списку городов. Приложение настроено как PWA (Progressive Web App): его можно установить на устройство и запускать в офлайн-режиме.

---

## Как реализовано

1. **Инициализация и сервер на Express:**
   * Проект инициализирован через `npm init`, установлен фреймворк `express`.
   * Настроена раздача статических файлов (HTML, CSS, JS, манифест и иконка) из папки `public`[cite: 4].

2. **Маршруты и обработка параметров:**
   * `GET /` и `GET /about` — отдают главную страницу и страницу с описанием проекта[cite: 4].
   * `GET /api/status` — возвращает JSON с текущим статусом работы сервера.
   * `GET /api/weather/:city` — обрабатывает параметр пути `:city` (поиск среди 5 заготовленных городов: *Moscow, Tomsk, London, Tokyo, Paris*) и query-параметр `?units=metric` / `?units=imperial` для переключения шкалы температуры между °C и °F. Если город не найден, сервер возвращает статус `404` и JSON `{"error": "City not found"}`.

3. **PWA и офлайн-режим:**
   * Добавлен и подключён к HTML-страницам файл `manifest.json` с параметрами приложения и иконкой[cite: 4].
   * Написан и зарегистрирован Service Worker (`sw.js`)[cite: 4], который при первом открытии кеширует статические файлы и позволяет открывать интерфейс без подключения к сети.

---

## Результат

* Сервер на Node.js запускается локально (`node server.js`) и корректно обрабатывает все маршруты, query-параметры и ошибки 404.
* Клиентская часть отправляет запросы к API и отображает температуру или сообщение об ошибке.
* В браузере доступна установка приложения на рабочий стол, а при включении режима *Offline* в DevTools страницы продолжают открываться из кеша.
